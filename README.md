# UNIDAVI - Desenvolvimento Web 2

## Descrição
Este repositório contém todos os arquivos das atividades realizadas na disciplina **Desenvolvimento Web 2**.  
O objetivo das atividades é aprofundar os conhecimentos adquiridos em Desenvolvimento Web 1, com foco em boas práticas de desenvolvimento, integração entre front-end e back-end, comunicação cliente-servidor via formulários PHP, e construção de interfaces interativas com JavaScript.

O repositório inclui exemplos práticos de:
- Formulários HTML integrados com PHP via métodos GET e POST.
- Captura e exibição de headers HTTP em requisições.
- Sanitização e manipulação de dados recebidos pelo servidor.
- Desenvolvimento de interfaces interativas com JavaScript puro.
- Construção de calculadoras com manipulação de DOM e suporte a teclado.
- Boas práticas de organização de código separando HTML, CSS e JavaScript.

Todas as aulas foram estruturadas de forma progressiva, permitindo acompanhar a evolução do conhecimento passo a passo.

## Índice

- [Aula 3](#aula03) – Formulários PHP e Calculadora com JavaScript  
  Desenvolvimento de dois exercícios práticos: um formulário HTML com envio de dados via GET e POST para um destino PHP que exibe os dados recebidos e os headers HTTP da requisição; e uma calculadora funcional com interface dark, suporte a teclado, feedback visual dinâmico no display conforme o sinal do resultado (positivo, negativo ou zero) e tratamento de erros de expressão.

## Instalação

Siga os passos abaixo para clonar e configurar o projeto localmente:

```bash
# Clonar o repositório
git clone https://github.com/Johannmk1/ProgramacaoWebII.git

# Entrar na pasta do projeto
cd ProgramacaoWebII
```

> Para executar os arquivos PHP, é necessário ter um servidor local configurado (ex: XAMPP, WAMP ou PHP embutido via `php -S localhost:8000`).
